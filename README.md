# ERP Sales & Inventory Management

A small ERP-oriented project for managing products, customers,
orders, inventory, and sales reports.

## Technologies

- Python
- MySQL
- mysql-connector-python
- SQL
- OOP concepts
- CRUD
- JOIN
- GROUP BY
- HAVING
- Subqueries
- SQL Views

## Database Structure

The database contains the following tables:

- Categories
- Customers
- Products
- Orders
- OrderDetails
- Inventory

## Python Features

The Python application connects to MySQL and provides:

- Product listing
- Adding products
- Updating products
- Deleting products
- Customer sales report
- Low-stock report

## SQL Reports

The project includes queries for:

- Products with categories
- Orders with customer information
- Order totals
- Total completed sales
- Best-selling products
- Customer purchase reports
- Low-stock products
- Subquery-based reports
- SQL Views

## Project Goal

The goal of this project is to demonstrate practical experience
with relational database design, SQL queries, and Python-MySQL
integration in an ERP-oriented environment.
